# DocTools Frontend

Read README.md and AGENTS.md first. This is an independent Next.js repository for the copied public Free DocTools branch. The homepage is /, the complete directory is /cong-cu, and tools are /<slug>; NEXT_PUBLIC_BASE_PATH is a build-time prefix (empty locally, /doc-tools on lpc.vn); legacy /doc-tools URLs redirect to root only when the prefix is empty. Read docs/upstream/doc-tools.md for the source behavior. Preserve the copied tool workspaces, catalog, engines and output behavior. The approved public website redesign lives in src/features/site and src/styles/site; the homepage and directory reuse the existing catalog and URL helpers. The prefixed homepage redirects to a trailing slash so it is controlled by the /doc-tools/ worker scope; Next skips its default trailing-slash redirect only in prefixed deployments. React Router uses a basename while internal route constants and leave guards stay rooted at /. utils/url prefixes browser resources and API URLs without changing external ERPCons links. docs/upstream-manifest.json records the original SHA-256 hashes.

Runtime composition is in src/runtime. Next.js hosts a persistent React Router data router. next.config.mjs replaces only useHubPrefs with the hydration adapter; src/proxy.ts handles legacy /doc-tools and ?tool links before SSR. Browser-only engines must not evaluate during server rendering. ToolsLayout composes the shared website header, the persistent tool scroll region, and a website-only footer. Tool workspaces use the full-width Chuyen Nho shell with a shared title, description and local-processing notice; the ERPCons brand panel is no longer mounted. src/styles/site/workspace-*.css adapts the shared flow, utility panels and PDF editor via scoped tokens without changing engines, stamp fonts or screen identity. Bootstrap tool modals inherit the same tokens through body:has(.cn-shell--tool). Directory filters use q and nhom query parameters and restore after hydration. The site uses self-hosted Be Vietnam Pro and blue/navy tokens scoped to the public website. Build regenerates the offline manifest from the built basePath including the directory, brand assets and emitted Next image sizes. Service worker registration, cache lookup and stale-build recovery are scoped to this app prefix. NEXT_PUBLIC_SITE_URL is the origin; metadata and sitemap add the prefix.

Tool Open Graph and Twitter metadata point to <basePath>/og/<slug>. The Node.js route prerenders PNG share cards for ready catalog tools and caches them with daily revalidation. src/features/site/server/tool-share-image.tsx renders the existing Bootstrap icon, catalog name/description, Chuyen Nho palette and local Be Vietnam Pro fonts with Arimo for symbol fallback through next/og; no external image or font requests are needed.

The only backend dependency is HTTP: BACKEND_URL configures the external NestJS counter API. Keep flat {ok,...} envelopes. The Free app has no local login; login/Pro links point to ERPCons.

Run npm ci, npm test, npm run build and npm run lint within this repo. Each repository owns its package-lock.json and dependencies. The lockfile was verified with Node.js 24 and npm 11.11.0. Do not add npm workspaces, file dependencies or links to the backend repository.

Preserve Vietnamese UTF-8 without BOM. UI verification requires responsive screenshots and real file processing. Do not commit or push without explicit user instruction.
