# Entertainment card artwork

52 playing-card SVG faces: Dmitry Fomin, CC0, https://commons.wikimedia.org/wiki/File:English_pattern_playing_cards_deck.svg. Extracted from the source sheet without redrawing.

78 Rider-Waite-Smith Tarot JPEG faces: Pamela Colman Smith, public-domain files from Wikimedia Commons. Per-card source pages and license links are in public/assets/entertainment/sources.json. Both backs are original Chuyen Nho SVG patterns. All assets are served locally; the ID registry matches backend deck IDs. Unknown IDs show a readable fallback.

Revealed cards open a keyboard-accessible image dialog without a new draw request. Reversed Tarot rotates the complete image. The tools are available directly without opt-in flags. Artwork does not add interpretation content. See backend/docs/entertainment.md for the API and privacy contract.
