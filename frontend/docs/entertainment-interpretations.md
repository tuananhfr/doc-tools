# Vietnamese entertainment interpretations

`features/tools/entertainment/data` owns original Vietnamese reference copy, version `cn-ent-interpretation-vi-v1`. It contains 156 Tarot orientation entries (78 cards), 52 playing-card entries and 70 numerology metric/value entries. Data is keyed by the existing card IDs and by metric ID plus value; labels, source links and layout are separate. The feature is lazy-loaded with the existing tool screens. No AI call or account-history integration is introduced.

Tarot follows Rider–Waite–Smith symbolism, with Waite's historical text and modern Labyrinthos/Biddy Tarot themes as reference. Playing cards retain one editorial selection of traditional suit/rank meanings, checked against Grimoire and the historical public-domain book *Telling Fortunes by Cards* (1914). Sources disagree on some meanings; the source panel discloses this. Each entry states its meaning directly, adds a concrete example or application, and gives simple advice. Court cards describe qualities or roles without fixed gender or appearance. The copy is not a translation of a site's full readings and is not presented as endorsed by a source author. Per-kind links live in `config/interpretation-sources.ts`.

All existing draw counts retain their behavior: cards 1/3/5/7/9, Tarot 1/3/5/7/10. Each count has one explicit position layout in `config/draw-spreads.ts`; the expanded layouts are editorial adaptations, not advertised as a canonical Celtic Cross. The layout is visible before drawing and stays fixed for the result. Each revealed card has its own meaning; unrevealed cards expose no meaning in the rendered DOM. The overview is shown only after all cards are revealed. Unknown IDs/orientations produce an explicit missing-content message, never an invented fallback.

Numerology preserves `pythagorean-total-draft-v1`: sum all input digits, preserve 11/22/33 at each step, reduce the birthday, strip accents/Đ from the name, AEIOU vowels and Y consonant. Birthday can only produce 1–9 or 11. The other five metrics use 1–9/11/22/33. Personal-year master values are interpreted with cycle roots 2/4/6 plus a separately described master-number nuance. A null vowel/consonant group receives no interpretation. These conventions differ from some source calculators and are disclosed next to the source list.

`services/card-reading.ts` and `numerology-reading.ts` perform deterministic lookups without changing the raw result. `draw-conclusion.ts` connects the actual situation and obstacle with advice, support and conditional direction where those slots exist. Each spread position has an explicit semantic role. Tarot has 156 orientation-specific synthesis cues and playing cards have 52; each cue contains complete authored sentences for the situation, obstacle, obstacle reasoning and conditional direction. The composer joins sentences without inserting noun fragments into boilerplate. A favorable card in the obstacle slot is not announced as a favorable outcome. A difficult support card instead offers a way to seek help. Ten-card layouts use the existing next-step slot for advice. All slots remain visible in the expandable reasoning with actual labels and orientations; reasoning explains the card's basis rather than copying the final advice. The short narrative prioritizes the situation, obstacle, support, action and direction.

`numerology-conclusion.ts` relates the core metrics in their distinct roles, prioritizing Life Path with Soul Urge, then available alternatives. Remaining metrics can form a second explanatory pair; Birthday also appears in the reasoning. Each metric cue is a complete sentence with a clear subject; forty-five original editorial links cover the pairs of base themes 1–9 with practical cautions and advice. These links are not presented as a standard compatibility system or a verdict that two numbers conflict. Cues keep the distinct meanings and labels of 11/22/33 while relating their underlying themes 2/4/6. Null metrics contribute no inferred desires or traits. Personal Year has a separate block showing the selected year, its separately authored theme sentence, how it relates to Life Path if available, and year-specific advice. Core reasoning shows the actual metric labels and reference meanings rather than repeating the narrative.

`ReadingOverview` presents “Kết luận chung” immediately, with “Vì sao có nhận xét này?” in a native expandable section. This replaces the former list of first sentences. `reading-report.ts` exports the exact same conclusion paragraphs, advice, year block and reasoning, followed by the full individual meanings and provenance. The synthesis version is `cn-ent-conclusion-vi-v1`, separate from the unchanged reference library version. Existing draw-key, expiration, retry and export validation remain. No question/topic input or predictive score is introduced; conclusions remain general reference readings.

Numerology explanations, strengths, difficulties and advice are authored separately for every metric/value pair. The same number must not reuse one personality profile across Life Path, Birthday, Personal Year, Expression, Soul Urge and Personality. Each metric also explains its role and calculation inputs. Personal Year uses “Nên tập trung” and “Cần tránh” rather than labeling year themes as personal strengths and weaknesses.

The corpus is Vietnamese. Every locale has the new UI keys; English and the existing English-fallback locales explicitly disclose that readings are Vietnamese. Corpus sections set `lang="vi"` and `dir="ltr"`. The existing site font, light/dark tokens and responsive shell are preserved.

Backend `GET /api/v1/ent/tools` advertises interpretation availability for these three tools, with a separate EDITORIAL/vi library source. Calculation source IDs and rule versions in execution responses remain untouched. Calendar folk-rule availability remains separate.
